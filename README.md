# MindPulse AI

**Privacy-Centered Digital Wellbeing Companion**

MindPulse AI is a full-stack mobile wellbeing platform built with Flutter, Kotlin, Node.js, FastAPI, and MySQL.

## Key Features

- Daily wellbeing check-ins
- Privacy-preserving phone-usage insights
- Permission-controlled movement context
- Deterministic Human Companion suggestions
- Helpful and Not helpful feedback
- Same-day suggestion suppression
- Secure JWT authentication
- Authenticated AI Coach conversations
- Safety-aware response handling
- No automatic emergency-contact actions

## Responsible-AI Boundary

MindPulse provides informational wellness support. It is not a diagnostic tool, therapist, clinical product, or emergency service.

## Technology Stack

- Flutter and Dart
- Kotlin and Android MethodChannel
- Node.js and Express
- FastAPI and Python
- MySQL
- JWT authentication

## Development Status

The project is under active development. Experimental model results are not presented as evidence of clinical validity or production readiness.
