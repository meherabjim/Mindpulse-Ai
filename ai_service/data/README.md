## Directory Policy

The demo dataset is included for non-clinical engineering demonstrations and reproducibility.

The following data must remain outside the public repository:

- Real user records
- Raw production exports
- Private research data
- Unlicensed external datasets
- Credentials or personal identifiers

Synthetic benchmarks must not be described as clinical effectiveness or production readiness.
