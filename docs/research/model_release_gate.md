## Terminology restriction

General screens should use **Wellness Strain**, **Stress Load**, or **Work/Study Pressure**.

**Burnout** must not be presented as a medical diagnosis and should be limited to a clearly occupational context.

## Release decision

The release gate remains closed until every mandatory item has verifiable evidence.
